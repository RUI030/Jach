The harness checks, so the model does not have to remember

Each behaviour from the last section gets a mechanism that does not depend on the prompt being followed.

Behaviour 1

Repeats the same step

A failed turn is folded to one line as soon as the next call is made, so the failed code is not there to copy.

  • An identical failed call is refused
  • Stall rules stop the step: same error 3 times, 5 failures, a file returning to an earlier state
  • A stalled step goes to an admin model
Built
Behaviour 2

Ignores instructions

Rules are gates, not prompt text. The model saying "done" never passes one.

  • jac check after every write; only the first error is shown
  • submit runs the app in a real browser and returns what the page shows
  • Code conventions exist only where a script checks them
Built

Fold: failures become one line

Built

     Unknown, cannot access attribute "title"
[m5] edit frontend.jac -> failed: old-not-found

  • Only the newest failure is shown in full; older ones keep the call, the status and the compiler's message
  • No line numbers and no source in a folded line: the file has changed, and failed code is what gets copied
  • Successful turns stay in full; the context resets per task
  • The view never shows who acted: an admin fix reads as an ordinary turn
UnfoldDesigned

unfold(m4) returns the full turn as a new tool result. History is not rewritten, so the prompt cache stays valid.

Training samples are rendered by the same code, so the model is trained on exactly what it sees at run time.

The same gate judges the admin. It gets the conventions as AGENTS.md: nodes and edges for data, a walker when a read walks more than one hop.

From log to samples

Designed
  • One append-only log per run; every prompt saved in full
  • One main sample per session, plus one per failure that was fixed
  • Failed turns stay in the sample with weight 0
  • The admin's fix is replayed as the small model's own tool calls
  • stuck calls and hints are removed: the model never learns that help exists

Takeover is built with Codex as admin. Fresh, Advise and the replay are not.
